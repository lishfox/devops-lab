# Как писать карточки

## 5 правил

1. **Одна карточка — один факт.** Если в ответе есть «и», «а также» или список из 3+ пунктов, это две карточки.
2. **Ответ короткий**: 1–2 строки текста или до 3 строк кода. Его читают с телефона.
3. **Ответ проверяемый.** Глядя на обратную сторону, ты сразу знаешь, ответил правильно или нет.
   «Расскажи про X» не годится, «Что выведет X?» годится.
4. **Вопрос понятен без контекста.** Через месяц ты не вспомнишь, к чему он был. Пиши «В GitHub Actions…», «В `run:`…».
5. **Лучшая карточка — твоя ошибка.** «Я думал X, оказалось Y» превращается в вопрос, на котором ты ошибся.

## 4 вида карточек

| Вид | Лицевая сторона | Обратная |
|---|---|---|
| Предсказание | кусок кода + «что будет?» | итог + почему, одной строкой |
| Найди ошибку | кусок кода с ошибкой | что не так и как правильно |
| Как сделать | «Как …?» | команда или 1–3 строки кода |
| Отличие | «Чем X отличается от Y?» | по строке на каждое |

Предсказание и «найди ошибку» запоминаются лучше всего: они тренируют то же, что нужно в работе.

## Плохо → хорошо

Плохо — одна карточка про всё:
```yaml
- id: output-all
  front: GITHUB_OUTPUT
  back: Файл, куда шаг пишет outputs в формате name=value, шагу нужен id,
    читать через steps.id.outputs.name, для многострочных значений свой синтаксис...
```

Хорошо — разбито и проверяемо:
```yaml
- id: output-write
  front: Как шаг GitHub Actions отдаёт значение `name` дальше?
  back: |
    ```
    echo "name=value" >> "$GITHUB_OUTPUT"
    ```

- id: output-needs-id
  front: |
    Шаг пишет в `$GITHUB_OUTPUT`, но `steps.???.outputs.name` не читается. Чего шагу не хватает?
  back: "`id:` — без него к выходам шага не обратиться."
```

## После задачи — 2–3 карточки, 5 минут

1. **Твоя ошибка** → карточка-предсказание.
2. **Правило**, которое её объясняет → «как сделать» или «отличие».
3. *(по желанию)* **Инструмент**, который её ловит.

## Шаблон и ловушки YAML

```yaml
- id: task01-что-то   # латиница, не меняется никогда
  tags: [gha]
  front: Вопрос в одну строку
  back: |
    Ответ. Код:
    ```
    if: inputs.greet
    ```
```

- Есть `: ` или текст начинается с `` ` `` → оберни в кавычки `"..."` или пиши через `|`.
- Код — в блоке ```` ``` ````, `inline` — в обратных кавычках, **жирный** — в `**`.
- Сломал YAML — workflow `anki` упадёт и покажет строку с ошибкой.
