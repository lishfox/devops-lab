# devops-lab

Учебная лаборатория DevOps: сломанные workflow, которые надо починить. Всё работает с телефона,
код выполняется на раннерах GitHub Actions.

## Как решать задачу с телефона

1. Открой условие в [`tasks/`](tasks/).
2. Открой файл задачи в браузере → ✏️ (Edit) → поправь → **Commit changes** прямо в `main`.
3. Коммит сам запустит workflow. Вкладка **Actions** → свой запуск → job `check`.
4. Ручной запуск: Actions → workflow → **Run workflow** (работает и в приложении GitHub).
5. Красный `check` — читай его лог: там написано, что не так.

Подсказки в условии открывай по одной. Сломал файл совсем — смотри историю коммитов и откатывай.

## Куда можно подсматривать

Правило одно: смотреть можно на всё, что в реальной работе тоже было бы под рукой.

- ✅ **Лог и аннотации своего запуска.** В первую очередь. Читать логи — основной навык DevOps.
- ✅ **Код job `check`.** Это как тест в настоящем проекте: он говорит, *что* должно получиться, но не *как*.
- ✅ Документация GitHub, поиск, чужие workflow (Meshery и другие), `actionlint`.
- ✅ У Claude — объяснение понятия («что такое контекст `needs`»), не решение задачи.
- ⚠️ Подсказки в условии — по одной и только когда застрял.
- ❌ Менять `check` под свой ответ. В настоящем проекте подгонка теста — худшее, что можно сделать.
- ❌ Просить готовое решение до третьей подсказки.

## Колода AnkiDroid

Карточки лежат в [`anki/`](anki/), workflow [`anki`](.github/workflows/anki.yml) собирает из них колоду.

- Скачать: <https://github.com/lishfox/devops-lab/releases/download/anki/devops.apkg> → открыть в AnkiDroid.
- Обновить: скачать и импортировать снова. Прогресс сохранится, если `id` карточек не менялись.
- Новая карточка: добавь запись в `anki/*.yaml`, коммит соберёт колоду сам.
